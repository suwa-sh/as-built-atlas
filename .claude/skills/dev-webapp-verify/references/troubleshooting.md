# 画面の確認での、はまり所

| 起きること | 原因 | 直し方 |
|---|---|---|
| 画面を直したのに、変わらない | 見本は、配布物のイメージの中の画面を配っている。イメージを作り直していない | `scripts/redeploy.sh` を実行する |
| 集計や meta を変えたのに、画面に出ない | meta と宣言は、集計 (build) のときに DuckDB に書く。起動し直しただけでは変わらない | `scripts/redeploy.sh --build` |
| `redeploy.sh` が「build が失敗した」で止まる | 集計が失敗した。画面は、前の集計表のまま | 出力の末尾を読んで直す。直るまで、画面で確かめたことにしない |
| 作業定義の表示名を変えたのに、出ない | 同上 (表示名は、集計のときに書く) | 集計し直す |
| 「mart が古い版で作られている」と出る | 用語集の入っていない、古い版の DuckDB を開いている | 集計し直す |
| 片方の見本だけ、表示が古い | 起動し直したのが片方だけ | 分析リポジトリを 2 つとも渡す |
| このリポジトリの `profiles/` を直したのに、見本の集計に効かない | 集計が読むのは、分析リポジトリの中のプロファイルのコピー (作業定義の `profile.dir`)。コピーは、`upgrade` でしか置き換わらない | `scripts/redeploy.sh --upgrade` |
| 集計で「プロファイルのコピーが、配布物と違う」と警告が出る | 配布物 (イメージ) を新しくしたが、分析リポジトリの中のコピーを置き換えていない | `scripts/redeploy.sh --upgrade` |
| 分析リポジトリの中でプロファイルを直したのに、集計に効かない | 作業定義の `profile.dir` とは別の場所を直している | `profile.dir` の場所を確かめる |
| コンソールに 404 が 1 件出る | `favicon.ico` が無い。画面の変更とは関係ない | 無視してよい |
| 撮影が、ブラウザの起動で失敗する | playwright と、入っているブラウザの版が合わない | `uv run --with playwright playwright install chromium`。別の場所のブラウザを使うなら、`ABATLAS_CHROME` を設定する |
| `test_terms.py` が落ちる | 画面のコードに、呼び名を直接書いた | `term("<id>")` で引く。用語集に無い概念なら、`schema/vocab/terms.yaml` に足す |
| `test_webapp.py` が落ちる | 層の向きを破った、名前付きでない `import` を書いた、外部の URL を読んだ | `docs/rules/webapp.md` の「作りの決まり」 |
| 回転したときだけ接続先が図の外に切れる | 初期視点での高さだけで表示範囲を決めている | 「上から」を選んで左右に一周回し、最外周と各円筒の見出しが初期倍率の表示範囲に収まることを確かめる |
