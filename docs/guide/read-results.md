# 結果を読む

[← 手引きの入口へ](README.md)

分析と集計が済んだ後に、結果を読む方法です。
人は画面で読み、エージェントは MCP で読みます。
どちらも、同じ集計表を読みます。

## 画面を起動する

分析リポジトリで、次を実行します。

```bash
docker compose up -d api
```

ブラウザで <http://localhost:8765> を開きます。
ポートは、`.env` の `ABATLAS_PORT` で変えられます。

## 知りたいことから、開くページを選ぶ

画面のメニューは、利用者の問いに対応しています。

| 知りたいこと | 開くメニュー | 見るもの |
|---|---|---|
| 全体は、どんな層でできているか | 構成 (architecture) | 層のつながりの図。「3D」のタブでは、入口から処理、データ、外部 API までを立体で辿れる |
| どんな入口があり、何をするか | 入口 (entry point) | 入口の階層を 1 段ずつ降りる。入口を選ぶと、触る相手の表と、選んだ相手までの経路が出る |
| このデータを直すと、どの入口に影響するか | データ (datastore) | データの種類ごとの読み書きの表。データを選ぶと、触る入口と、入口からそのデータまでの経路が出る |
| この外部サービスを、どの入口が呼ぶか | 外部接続 (external API) | 外部サービスの一覧。1 件を選ぶと、呼んでいる入口と経路が出る |
| この共通処理を直すと、どの入口に影響するか | 共有処理 (shared function) | 2 件以上の入口から呼ばれる処理の一覧。1 件を選ぶと、呼んでいる入口と経路が出る |
| この列、設定、権限の確認を直すと、どの入口に響くか | 分析の観点 (aspects) | 答える問いごとのタブ。直す物を選ぶと、関わる入口と、根拠の場所が出る |
| 分析はどこまで進んだか。不明な点は何か | 分析の状態 (analysis status) | 進み具合と、不明な点の一覧 |
| 集計表そのものを見たい | 集計表 (mart) | 表の全体。同じものを読む API の URL と、MCP の呼び方 |

メニューの項目は、対応する集計表があるときだけ現れます。例外は 2 つです。集計表 (mart) は、いつもあります。構成 (architecture) は、プロファイルが層を持つときに現れます。

## 画面を読むときに知っておくこと

| こと | 内容 |
|---|---|
| 根拠 | 経路の各段に、根拠のファイルと行が付く。対象のコードを開いて確かめられる |
| 不明 | 分析で確かめられなかった主張は、「不明」として理由つきで出る。無かったことにはしない |
| 分析済みの範囲 | 分析していない入口があるときは、その旨がページの上に出る。表に無い入口は、「影響しない」ではなく「まだ分析していない」かもしれない |
| 包む入口 | 画面を持つシステムでは、共通の枠を別の入口として分析する。枠の処理は、枠のページで見る。画面のページには足し合わせない |
| 件数の上限 | 一覧は 50 件ずつ読む。上限で切った図や表には、切ったことが上に出る |

分析結果を直した後は、集計をやり直すと画面に反映されます。
「分析の状態」のページから、集計をやり直せます。

## エージェントから結果を聞く

自分のコーディングエージェントに、MCP を登録します。
Claude Code の例です。

```bash
claude mcp add --transport http abatlas http://localhost:8765/mcp
```

登録すると、エージェントが次のツールを使えます。

| ツール | できること |
|---|---|
| `describe_atlas` | 分析対象、プロファイル、言葉の定義を読む。最初に呼ぶ |
| `list_marts` | 集計表の一覧を読む |
| `describe_mart` | 集計表 1 つの説明と件数を読む |
| `query_mart` | 集計表の行を、絞り込んで読む |
| `group_mart` | 列の値ごとにまとめた件数を読む (例: データごとの、触る入口の数) |
| `recompute` | 集計をやり直す |

頼み方の例です。

- 「注文のテーブルに書き込む入口を、根拠の行と一緒に挙げて」
- 「この共通関数を呼んでいる入口は、いくつあるか」
- 「認証の確認が記録されていない入口を挙げて」

エージェントの答えは、分析結果の範囲に限られます。
分析していない入口の動きは、答えられません。
どの入口が分析されていないかと、記録された不明な点とその理由は、MCP で調べられます (例: 「まだ分析していない入口を挙げて」)。
