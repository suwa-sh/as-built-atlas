# 0033. 今回の入口と作業を一度で承認する

- 状態: 採用
- 記録した日: 2026-11-22

## 背景

差分の判定は入口単位で行う。共通の変更が多数の入口に及ぶと、人が同じ理由を何度も確認していた。

## 決定

取りまとめるエージェントが入口の採否と作業の案を作る。調査しても判断できない点には、対応する入口をまとめて質問する。人の回答と案への承認を区別する。全体の承認時に固定した案を再計算し、採否、再利用記録、実行する仕事を入口一覧の一回の置き換えで保存する。

| 検討した方法 | 判断 |
|---|---|
| 入口ごとに人の承認を受ける | 同じ運用判断を複数の入口で繰り返す |
| 件数や AI の確信度で自動承認する | 根拠が明確な大量の再分析にも、用途が不明な入口1件にも対応しにくい |
| 今回の案全体を承認する | 人は判断が残る点に集中でき、承認した範囲を後から追える |

## 結果

実行は従来どおり入口単位。取りまとめ役は完了した仕事を検査し、続きから実行できる。以前の入口別の再利用記録も引き続き検査できる。[操作手順](../architecture/impact.md)
