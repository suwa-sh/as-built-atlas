# 0008. 検査と列挙も、作業定義からプロファイルを読む。古いコピーは警告する

- 状態: 採用
- 記録した日: 2026-11-15

## 背景

[0006](0006-profile-dir-single-source.md) で、集計は作業定義の `profile.dir` を読むようにした。
しかし、検査と列挙は、`--profile` で渡されたファイルを読むままだった。

- 「同じファイルを渡す」を、人と手順書の注意に頼っていた。違うファイルを渡しても、気づけない。
- `--profile` を省くと、プロファイルとの突き合わせが、何も言わずに省かれた。
- 配布物を新しくして、分析リポジトリの中のコピーの更新を忘れても、集計は何も言わなかった ([0006](0006-profile-dir-single-source.md) の残る課題)。

## 決定

- 検査 (`validate entries` / `validate result`) と列挙 (`enumerate`) は、`--profile` を省くと、作業定義の `profile.dir` から、集計と同じプロファイルを読む。読んだ場所を出す。
- `--profile` を渡されたら、それを使う。集計が読むものと違うときは、警告する。
- 省いたが読めないとき (分析リポジトリの外、場所に無い) は、読めない旨を出して、突き合わせを省く。黙って省かない。
- 読み先は、検査するファイルごとに決める。そのファイルを含む、いちばん内側の `analysis/` の親が分析リポジトリで、そこに作業定義が無ければ外側へは進まない。カレントディレクトリも見ない (関係の無いプロファイルを当てないため)。
- この checkout の `examples/` に置かれた公開の見本 (分析リポジトリとして初期化していない。作業定義は配布物のコピーを指すが、`.abatlas/` が無い) に限り、その旨を出して、配布物の `profiles/<id>` を読む。コピーの元と同じものなので、突き合わせを省くより確かめられる。それ以外の場所 (checkout の外、checkout の中の `spike/` など) の分析リポジトリでコピーが無いときは、切り替えない (検査だけが、集計の読めないファイルで通ることを避ける)。
- 集計は、読んだプロファイルが配布物のコピーで、中身が配布物と違うとき、警告する。止めない。自分用に写したプロファイルは、対象外。

## 捨てた案

| 案 | 捨てた理由 |
|---|---|
| `--profile` を無くす | 分析リポジトリの外 (このリポジトリの checkout、見本の検査) で、プロファイルを渡す手段が要る |
| 違う `--profile` を渡されたら止める | 別のプロファイルで試す使い方 (プロファイルを直している途中の検査) を塞ぐ |
| コピーが古いとき、集計を止める | コピーが古くても、集計の結果は一貫している (検査・列挙・集計が、同じコピーを読む)。止めると、更新できない事情があるときに画面を見られない |
| 版の番号で比べる | 版を上げない直しを見逃す。中身で比べる |

## 結果

- [0006](0006-profile-dir-single-source.md) の残る課題のうち、「コピーと配布物の版が違うとき、警告しない」は解消した。`dbt-template/` が外を指すリンクの件は、残る。
- 手順書と skill から、`--profile` の指定を外した。
- 最新の状態: [../reference/profiles.md](../reference/profiles.md) の「ツールが読むプロファイル」。
