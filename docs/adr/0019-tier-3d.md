# 0019. 3D 構成図は、区分ごとに面を分ける

- 状態: [0020](0020-concentric-tiers.md) で配置を更新
- 記録した日: 2026-11-20

## 背景

入口別の断面図では、各処理の層と接続先を追える。一方、同じ区分で働く層を把握しづらかった。Next.js では、サーバー側のライブラリ境界と外部サービスの接続先がどちらも external と呼ばれる。

## 決定

構成を立体で見る最初の画面では、役割を共有する層を同じ面に載せる。データストアと外部サービスはそれぞれ専用の面を持つ。視点の変更では同じ空間上の点と線を投影し直す。

## 検討した案

| 案 | 判断の理由 |
|---|---|
| 層ごとに 1 枚の面を作る | 個々の処理を読む用途に向くため、入口を選んだ後の詳細で使う |
| 区分を面にし、層をその上に置く | 並列の入口と区分の境界を同時に読み取れるため採用した |

## 結果

全体と入口別の構成で同じ基準の配置を使える。画面の説明は [webapp](../architecture/webapp.md) にある。
