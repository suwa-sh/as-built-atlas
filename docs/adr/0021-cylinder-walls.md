# 0021. 層を同心円筒の側面に配置する

- 状態: [0022](0022-resource-rings.md) で資源の配置を更新
- 記録した日: 2026-11-20
- 更新する決定: [0020](0020-concentric-tiers.md)

## 背景

円筒の上面を扇形に分けると、同じ層の処理は一つの高さに広がる。入口から伸びる多数の線を追うため、真上では点の所属を半径で読み、斜めからは各層に散らばる点を個別に選びたい。

## 決定

区分ごとに半径の異なる円筒を、同じ高さと中心軸で入れ子にする。各層には円筒の側面の一部を割り当てる。処理の点は半径を固定し、層の範囲内で角度と高さを変えて配置する。高さは表示上の位置を表す。呼び出しの順序は点を結ぶ線から読む。

## 検討した案

| 配置 | 見え方 |
|---|---|
| 上面の扇形 | 真上で層に面積があり処理を選びやすい。横から見ると一つの層の点が同じ高さに並ぶ |
| 円筒に沿う曲面 | 真上で同じ区分の点が輪になり、傾けると各層の点が縦にも広がる |

## 結果

透明な曲面越しに、内側の層や奥の処理に続く線をたどれる。データストアはアプリケーションと同じ軸に、ひと回り広い低い円筒として置く。種類ごとに側面を分けてテーブルやキューを配置する。外部 API は独立した小さな円筒の側面に接続先を置き、アプリケーションの外に出る線を見分けられるようにする。操作は [画面の説明](../architecture/webapp.md) にある。
