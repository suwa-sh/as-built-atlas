# 0026. 区分の詳細で層の側面を入口のパスに分ける

- 状態: 採用
- 記録した日: 2026-11-20
- 関連する決定: [0025](0025-tier-drilldown.md)

## 背景

区分の詳細では一つの層を一段に置く。複数の入口を重ねると、同じ段の点がどの入口から来たのか読み取りにくい。

## 決定

表示中の入口のうち、その区分を通る入口の階層パスに円周を等分する。一つのパスに各段で同じ角度を割り当てる。処理が記録された層とパスの組だけに曲面を描き、その上に入口ごとのフレームを置く。面は段とパスの組で選択できる。

## 結果

一つの入口による層間の呼び出しを、方角を手掛かりに追える。面の番号と凡例で、同じ種類の入口も個別に識別できる。パスには集計済みの入口の識別子を使うので、バッチやモバイルのプロファイルにも同じ配置を使える。
