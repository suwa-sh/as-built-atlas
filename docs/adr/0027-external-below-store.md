# 0027. 外部の接続先を最外周のまま最下段に置く

- 状態: 採用
- 記録した日: 2026-11-20
- 更新する決定: [0023](0023-tier-levels-and-calls.md)

## 背景

斜めの視点では、アプリケーションからデータストアと外部サービスへのアクセスを上から順に読みたい。真上からは、外部サービスの接続先がアプリの外側にあることを示したい。

## 決定

アプリケーションの区分をプロファイルの順に積み、その下にデータストア、最後に外部の接続先を置く。半径は外部を最大、データストアを最小とする。

## 結果

二つの視点で、高さはアクセス先の並び、半径はアプリとの境界を示す。外部への呼び出し線は実際の呼び出し元と接続先を直接結ぶ。
