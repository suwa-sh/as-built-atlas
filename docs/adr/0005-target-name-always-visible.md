# 0005. 分析対象の名前を、どのページでも見えるようにする

- 状態: 採用
- 記録した日: 2026-11-15

## 背景

画面のどこにも、分析対象のシステムの名前が出ていなかった。
複数のシステムの画面を並べて開くと、どれを見ているか分からなかった。
対象のリポジトリ名とコミットは作業定義にあるが、集計の結果には入っていなかった。

## 決定

- メニューの見出しを、道具の名前から、分析対象の名前に変える。下に小さく、コミットの先頭 7 桁を出す。
- 畳んだ帯 (縦書き)、狭い画面の上の帯、ブラウザのタブにも出す。
- 道具の名前は、本文の下のフッターに出す。
- 作業定義に、任意の表示名 `target.name` を足す。無ければ、`repo` の最後の区切りより後ろを使う。
- build が、`name` / `repo` / `commit` を `meta.target` に書く。

## 捨てた案

| 案 | 捨てた理由 |
|---|---|
| 各ページの題の上に 1 行出す | 全ページで本文が 1 行下がる。メニューの見出しと情報が重なる |
| 構成のページにだけ出す | 「どのページでも見える」を満たさない |
| 画面が作業定義を直接読む | 画面は API だけを読む決まり ([../rules/webapp.md](../rules/webapp.md)) |

## 結果

- 表示名を変えたら、再集計が要る (名前は build のときに書くため)。
- 表示名は作業定義だけに書く。分析結果と入口の一覧には写さない。
