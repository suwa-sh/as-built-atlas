# 0023. 高さで区分を分け、層間の直接呼び出しを選べるようにする

- 状態: 高さの配置は [0027](0027-external-below-store.md) で更新。層の組の選択は [0025](0025-tier-drilldown.md) で更新
- 記録した日: 2026-11-20
- 更新する決定: [0022](0022-resource-rings.md)

## 背景

真上の同心円では点の所属が分かるが、複数の入口の線を重ねると、一つの区分の中でどの層がどの層を呼ぶかを追いにくい。

## 決定

外から内への区分の順を、上から下への配置にも使う。初期視点は各段が分かれる斜めとする。表示中の呼び出しツリーの親子を、同一区分に属する呼び出し元の層と呼び先の層の組でまとめる。同じ層の中の親子も数える。層の組から個々の親子を選び、入口からその関数までたどれるようにする。

## 結果

入口のパスは見る範囲を決め、層の組はその範囲で記録された直接呼び出しを選ぶ。接続先への読み書きと区分をまたぐ呼び出しは全体表示で確認できる。
