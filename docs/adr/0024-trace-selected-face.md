# 0024. 面を選ぶと各入口からの呼び出しを強調する

- 状態: 採用
- 記録した日: 2026-11-20

## 背景

3D 図で RDB を選ぶと各テーブルの直接の読み書きが見えたが、どの入口からどの層を通ってそこに至るかは点ごとに調べる必要があった。

## 決定

選択した面に属する点を起点にして、表示中の分析結果の親子関係を入口まで遡る。点を選んだときと同様、選択した処理の直接の呼び先・読み書きも強調する。共通する経路は一度だけ描く。

## 結果

同じ資源に触れる複数の入口を同時に読める。選択した処理の呼び先が他の入口とも共有されている場合、遡る対象は選択した処理自身の祖先に限る。
