# 0022. データストアを最内周、外部 API を最外周に配置する

- 状態: [0023](0023-tier-levels-and-calls.md) で高さと初期視点を更新
- 記録した日: 2026-11-20
- 更新する決定: [0021](0021-cylinder-walls.md)

## 背景

幅広い土台と横に離した筒は、斜めからデータストアと外部サービスを見分けやすい一方、真上からはアプリに対する内外の関係を半径で読み取れなかった。

## 決定

すべての円筒の軸をそろえ、データストアを最内周、外部サービスを最外周に置く。両者の間に、プロファイルの順にアプリの区分を外から並べる。データストアの側面はアプリの下に置く。図は真上の視点で開く。

## 結果

同じ処理からテーブルへの線は中心側に、外部 API への線は外周側に伸びる。半径は所属を表し、呼び出しの順序は分析結果の点と線で読む。
