# 0007. 仕組みの説明を主題ごとに分け、見た目の正本を 1 つにする

- 状態: 文書の分け方は [0035](0035-docs-by-reader-purpose.md) で更新
- 記録した日: 2026-11-15

## 背景

仕組みの説明は 1 ファイル (322 行) で、1 段落に 10 以上の事実が詰まった箇所があった。
図の描き方や色の決まりが、仕組みの説明と見た目の文書の両方にあり、片方が古くなっていた。
ルートの README の画像は、古い画面のものだった。

## 決定

- 仕組みの説明を、入口 (全体像・地図・言葉の表) と、主題ごとの 7 ファイルに分ける。
- 段落より、表・リスト・図で書く。図は mermaid で、実際に描いて確かめる。
- 見た目の決まり (色・線・余白・部品の形) の正本は、`DESIGN.md` の 1 つにする。仕組みの説明からは参照する。
- 文書は日本語の呼び名で書き、画面の呼び名との対応表を入口に置く。
- README の画像は、同梱の見本を今の画面で撮る。

## 捨てた案

| 案 | 捨てた理由 |
|---|---|
| 1 ファイルのまま、見出しを増やす | 長さは変わらず、知りたいことへ辿りにくい |
| 入口の文書を消して、主題ごとの文書だけにする | skill や設定が、入口の文書を参照している |

## 結果

- 配布先 (`.abatlas/docs/architecture/`) には `DESIGN.md` が無いので、リンクではなく文で指す。
- 文書の書き方の決まり: [../rules/docs.md](../rules/docs.md)。
