# 0020. 区分を同心円の帯、層を扇形に配置する

- 状態: [0021](0021-cylinder-walls.md) で配置を更新
- 記録した日: 2026-11-20
- 更新する決定: [0019](0019-tier-3d.md)

## 背景

一枚ずつ面を重ねた構成図では、アプリケーション内のライブラリ境界と接続先を離して読める。一方、複数の層が一つのアプリケーションを構成する様子を、回しながら眺めたい。

## 決定

区分ごとに半径が違う円筒を積み、その上面を層ごとの扇形に分ける。真上からは同心円、斜めからは区分の数だけ段のある円筒に見える。外から内への順番にはプロファイルの並びを使う。下の台の上面はデータストアの種類で分け、外部 API は離れた台に置く。各面に、分析した入口の処理と個々の接続先を点で置く。処理の親子と読み書きの相手を細線で結ぶ。入口が異なれば処理の点を分け、同じ資源パスの点は共有する。

## 検討した案

| 配置 | 読み取れること |
|---|---|
| 区分を別々の階に重ねる | 区分ごとの呼び出しを段に沿って追える |
| 半径の違う円筒を積み重ねる | アプリケーション内の所属がまとまり、下のデータストアと離れた外部サービスを見分けられる |

## 結果

上からは区分と層の所属を、傾けると接続先の位置を読める。入口を絞り込んでも配置と視点を保つ。操作は [画面の説明](../architecture/webapp.md) にある。
