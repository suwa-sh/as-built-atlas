# 0028. LP に製品マークを置き、分析の仕組みを暗色の面で示す

- 状態: 採用
- 記録した日: 2026-11-21

## 背景

README を中心に紹介していた時点では、製品名を文字だけで示していた。LP では、実際の画面をたどる部分から、分析結果を作り利用する仕組みの説明へと読み方が変わる。

## 決定

製品名と一緒に使えるマークを用意する。LP の技術思想の節に暗色を使い、推論と集計の範囲を図で示す。製品画面は元の配色で掲載し、調査対象や手順は画像の外の本文で説明する。

## 結果

ページの前後とブラウザのタブで同じマークを使える。実例から概念図に切り替わる位置が背景からも分かる。素材と使い方は[ブランド文書](../brand.md)にまとめる。
