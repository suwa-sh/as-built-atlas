# ADR

アーキテクチャ決定記録の索引です。1 決定 1 ファイル (`NNNN-<slug>.md`) で、背景・決定・捨てた案・結果を書きます。

- ADR は**経緯**の記録です。いま守ることは、`docs/` のほかの文書 (仕組みの説明、ルール) に書きます ([0001](0001-knowledge-placement.md))。
- 決定を変えるときは、新しい ADR を足し、古い ADR の状態を「置き換え済み (→ 新しい番号)」にします。古い ADR の本文は書き換えません。
