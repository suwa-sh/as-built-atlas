# 0030. LP の文章を、輪郭が見え始めてから読める濃さへ変化させる

- 状態: 採用
- 記録した日: 2026-11-21

## 背景

見出しと導入文を初めから読める濃さにすると、スクロールしたときに上下の移動が目立ち、文字が現れるタイミングを捉えにくかった。

## 決定

スクロールで登場する文章は、最初の数フレームでは文字の輪郭がかすかに見え、続いて読める濃さになるようにする。実画面のキャプチャは元の濃さで示す。動きを減らす設定や JavaScript 無効時には、最初から全文を表示する。スクリプトの読み込み中に画面に表示された文章は、そのまま読める状態を保つ。

具体的な開始位置と濃さは[ブランド文書](../brand.md)に記載する。
