# 0025. 個別の区分を開いて層間の呼び出しを見る

- 状態: 採用
- 記録した日: 2026-11-20
- 更新する決定: [0023](0023-tier-levels-and-calls.md)

## 背景

層の組を先に選ぶには、利用者が呼び出し元と呼び先を知っている必要がある。区分内にどんな関係があるかを眺めてから、一つの処理をたどりたい。

## 決定

全体図のアプリの区分名から、その区分の詳細を開く。詳細ではプロファイルに並ぶ層を上から一段ずつ配置する。各段の半径を変え、真上からも層を識別できるようにする。高さは層の順を表し、呼び出しの向きは点の間の矢印で表す。

## 結果

区分内の処理の点と、記録された直接の親子を同時に見られる。途中で他の区分を通る処理には短絡する線を作らない。全体図に戻ると、元の視点でデータストアや外部とのつながりをたどれる。
