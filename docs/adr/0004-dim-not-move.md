# 0004. 図の絞り込みと 0 件のものは、薄くするだけで位置を動かさない

- 状態: 採用
- 記録した日: 2026-11-15

## 背景

層の図に、絞り込みを足した。また、プロファイルにはあるが、この対象では使われていない層 (function が 0 件) の箱が、ほかの箱と同じ見た目で出ていた。
「分析が漏れているのか、本当に無いのか」が、図から区別できなかった。

## 決定

- 絞り込みは、合わない箱と線を薄くするだけにする。箱の位置は動かさない。
- function が 0 件の層は、箱を残して薄く描く (薄い罫の枠と灰の名前)。図の下の注記に、名前を出す。
- 線が 0 本でも、箱は描く。
- 絞り込みの「薄い」(全体が透ける) と、0 件の「薄い」(枠と文字の色) は、見た目を分ける。

## 捨てた案

| 案 | 捨てた理由 |
|---|---|
| 合わない箱・0 件の箱を図から外す | 分析が進むにつれて箱が増え、位置が動く。図の形を覚えたまま読めない |
| 0 件の箱も同じ見た目のまま | 使われていないことが伝わらない |

## 結果

- 使っていない層そのものを消したいときは、プロファイルを自分用に写して直す ([0006](0006-profile-dir-single-source.md))。
- 最新の状態: `DESIGN.md` の「構成の図」。
