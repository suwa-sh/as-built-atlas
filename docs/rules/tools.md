# ツールのルール

[← rules の地図へ](README.md)

対象: `abatlas/*.py` (検査、列挙、抽出器、ETL、集計、初期化と更新、API、MCP)。仕組みの説明は [../architecture/pipeline.md](../architecture/pipeline.md) と [../architecture/api.md](../architecture/api.md) です。

## 守ること

| 決まり | 理由 | 守っているもの |
|---|---|---|
| 文書のリンク切れと、配布先で切れるリンクは、テストで止める | 文書を動かしたときの見落としを防ぐ | `tests/test_docs.py` |
| 同じ入力から、同じ出力を出す (列挙、ETL、集計) | 再現できる処理は、決定論で行う | `tests/test_examples.py` (見本を生成し直して差が無い、列挙の出力と一致する)。同じ入力で 2 回動かして比べるテストは無い |
| **黙って別のものに切り替えない。** 指定されたものが無い・合わないときは、理由と直し方を出して止まる | 書き間違いに気づけず、別の入力で処理が進むのを防ぐ | `tests/test_layout_api_mcp.py` (プロファイルの読み先) |
| 検査・列挙・集計は、同じプロファイル (作業定義の `profile.dir`) を読む。検査と列挙の `--profile` は省ける。違うものを渡されたら、警告する | 検査と集計が、別の定義で動かない ([ADR 0008](../adr/0008-tools-read-profile-dir.md)) | 同上 |
| 配布物のコピーが配布物と違うときは、集計で警告する | 配布物を新しくして、更新を忘れたことに気づける | 同上 |
| 検査で省いたことは、指摘として出す (黙って省かない) | 「検査した」と「検査できなかった」を区別する | — |
| DuckDB は、別ファイルに作ってから入れ替える。検査に通らなければ入れ替えない | 読んでいる最中の API を壊さない。読めない宣言を出さない | `tests/test_round*_findings.py` |
| 集計は、警告で済むことでは止めない。止めるのは、結果が誤りになるときだけ | 例: 古い版のプロファイルで分析した結果は、警告と印だけ。全件の再分析が済むまで画面が見られなくなるのを避ける | — |
| 変換 (`migrate`) は、分析する側のファイルの、項目の名前だけを書き換える (形式で決まった場所だけ。例外は、文の中の「(tier: <id>)」)。書き換えた結果を読み直して、あるべき姿と突き合わせ、合わないファイルは、書き換えずに知らせる。配布物のコピーと、分析リポジトリの外には触らない | 利用者のファイルを、意図より広く変えない ([ADR 0010](../adr/0010-migrate-command.md)) | `tests/test_migrate.py` |
| API と MCP は、集計表の名前を知らない。宣言から動く | 集計表を足しても、コードを直さない | [marts.md](marts.md) |
| MCP は、API の薄い包み。同じ動きを 2 か所に書かない | 人とエージェントが、同じものを読む | — |

## 止まるときの出し方

エラーの文には、次の 3 つを入れます。

| 入れるもの | 例 |
|---|---|
| どのファイルの、どの項目か | `work-definition.yaml の profile.dir 'analysis/profiles/x'` |
| 何が合わないか | `に profile.yaml が無い` |
| どう直すか | `upgrade で置き直すか、profile.dir を直す (消すと配布物を使う)` |

## 分析リポジトリとの境

- 分析リポジトリの中で、OSS が持つパス (`.abatlas/`、`compose.yaml`、配布用の skill、hook) は、`upgrade` が置き換えます。利用者が直す場所にしません。
- 利用者が直すもの (独自の集計表、自分用のプロファイル) は、`analysis/` の下に置きます。
- 配布物の中身を変えたら、イメージを作り直して、分析リポジトリで `upgrade` を試します。

## 外から開ける相手

- API、MCP、画面は、Host がループバック名か、`ABATLAS_ALLOWED_HOSTS` に書いた名前のときだけ応えます。
- この検査を緩める変更は、理由を ADR に書きます。
